[DEV-1] drawMode is NOT stored in the undo snapshot.
Rationale: drawMode is a user preference (persisted in localStorage), not a move consequence.
If it rode in snapshots, undoing after a mid-game toggle would silently revert the user's
chosen mode. setDrawMode(state, mode) mutates state.drawMode directly and is never
snapshotted; undo therefore never changes the mode. All other snapshot fields stay as-is.

SEGMENT 1 - Engine & tests (engine.js, test_engine.js)

- setDrawMode(state, mode) -> 1|3.

  (d) stock draw/recycle. Read-only.

  executes via moveCards, returns {from,to,card} or null.

- createNearWinState(drawMode?): deterministic deal, foundations A..J all suits (44 cards),
  tableau[0..3] hold alternating-color K,Q stacks face-up, tableau[4..6] empty, stock/waste
  empty; canAutoComplete true immediately; 8 autoCompleteSteps win the game.
